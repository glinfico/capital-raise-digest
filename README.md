# Capital Raise Digest

**Independent capital-markets intelligence publication**  
Website: https://crd.glinfico.com

Capital Raise Digest (CRD) publishes capital-markets coverage, fundraising intelligence, and curated daily editions. This repository is maintained separately from FinVenturePro (BCD) and GLINFICO.FOD.

## Development

- Install dependencies: `npm install`
- Run locally: `npm run dev`
- Create production build: `npm run build`

## Deployment

The production build output is `dist/`. Configure the deployment project to use this repository's `main` branch and the build command above, then assign `crd.glinfico.com` to that deployment.

CRD is an editorial publication. Market data and editorial claims must be verified before publication; sample article content in the current build should be reviewed before being presented as verified reporting.
